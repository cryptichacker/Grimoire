# OWASP Top 10

The OWASP Top 10 is a periodically updated awareness document listing the ten most critical web application security risks, first published in 2003 and revised roughly every 3–4 years from data collected across the industry. Each edition below is its own note listing all ten categories.

## Notes on lineage
- The list reorders and merges categories each cycle based on real-world prevalence data and CWE mapping, so a risk "dropping" usually means others rose, not that it's solved.
- From 2021 onward, categories are numbered `A01…A10` and defined around **root causes / CWE groups** rather than individual attacks.
- Many items map directly to [[PortSwigger]] topics (e.g. Injection → [[SQL injection]], Broken Access Control → [[Access control]], SSRF → [[Server-side request forgery (SSRF)]]).
