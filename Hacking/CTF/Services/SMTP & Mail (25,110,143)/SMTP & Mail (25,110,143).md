# SMTP & Mail (25,110,143)

## Up
- [[Services]]

Mail services: **SMTP (25)** send, **POP3 (110)** / **IMAP (143)** retrieve (SSL variants 465/993/995). CTF value: **username enumeration** (VRFY/RCPT), reading mailboxes for creds/hints, and occasionally open-relay / version RCE.

---

## Enumerate

```bash
nmap -p25,110,143 -sC -sV $IP
nmap --script smtp-* -p25 $IP           # smtp-enum-users, smtp-open-relay, smtp-commands

# SMTP user enumeration (find valid users)
nc -nv $IP 25
VRFY root            # 252/250 = exists, 550 = no
# automated:
smtp-user-enum -M VRFY -U users.txt -t $IP
smtp-user-enum -M RCPT -U users.txt -t $IP     # if VRFY disabled
```

---

## Foothold Techniques

```bash
# read mail with creds (POP3)
nc -nv $IP 110
USER bob
PASS secret
LIST        # list messages
RETR 1      # read message 1 → creds, links, hints

# IMAP
nc -nv $IP 143
a login bob secret
a list "" "*"
a select INBOX
a fetch 1 body[text]

# send a phishing/malicious mail (if the scenario has a bot/user clicking) via swaks:
swaks --to victim@corp.local --from a@b.c --server $IP --body "http://$LHOST/x"
```

---

## Common Misconfigurations / Exploits

- **VRFY/EXPN/RCPT user enumeration** → valid usernames for spraying [[Password Cracking]]/[[SSH (22)]].
- **Mailboxes readable** with weak creds → passwords, reset links, internal hostnames.
- **Open relay** (`smtp-open-relay`) → send mail as anyone (client-side/phish scenarios).
- Old **Exim/Postfix/Sendmail** versions → RCE (`searchsploit exim` — e.g. CVE-2019-10149).
- Emails reveal the **email/username format** (`f.last@corp.local`) → user lists for AD/spraying.

---

## OSCP Tips

- Enumerate **usernames** here, then spray/brute elsewhere (AD, SSH) — don't brute mail itself.
- Read mailboxes fully — CTFs hide creds, reset links, and next-step hints in email.
- Note the **email format** to build user lists for [[Active Directory]].
- Check the **Exim/Postfix version** against searchsploit for direct RCE.
