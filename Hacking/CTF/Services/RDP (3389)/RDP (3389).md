# RDP (3389)

## Up
- [[Services]]

Remote Desktop (Windows GUI). Mostly a **way to use creds you found** — log in for an interactive session. Occasionally weak creds / version bugs.

---

## Enumerate

```bash
nmap -p3389 -sC -sV $IP
nmap --script rdp-ntlm-info,rdp-enum-encryption -p3389 $IP   # leaks hostname/domain/OS
crackmapexec rdp $IP -u user -p pass                          # validate creds (Pwn3d!)
crackmapexec rdp $IP -u users.txt -p passwords.txt --continue-on-success
```

`rdp-ntlm-info` leaks the **hostname/domain** (useful for [[Active Directory]]).

---

## Foothold / Access

```bash
xfreerdp /v:$IP /u:user /p:pass +clipboard /dynamic-resolution /drive:share,.
#   /drive: mounts a local folder → easy tool transfer
rdesktop -u user -p pass $IP
# pass-the-hash (Restricted Admin mode, if enabled):
xfreerdp /v:$IP /u:admin /pth:<NTLM>
```

---

## Common Misconfigurations / Exploits

- **Weak/reused creds** → full interactive desktop (easiest GUI foothold/privesc staging).
- **BlueKeep (CVE-2019-0708)** on very old unpatched Windows (RCE — unstable, last resort).
- **Restricted Admin mode** enabled → **Pass-the-Hash** over RDP.
- NLA disabled → some info leaks / attacks.

---

## OSCP Tips

- RDP is where creds from other services **pay off** — get a desktop, then run [[Windows PrivEsc]] enumeration.
- Use `xfreerdp` with **`/drive:`** to drop winPEAS/tools straight onto the box.
- `rdp-ntlm-info` gives you the domain/hostname even before you have creds → add to notes / [[Active Directory]].
- Brute only if hinted, and mind **account lockout**.
