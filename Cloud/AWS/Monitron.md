# Monitron

## Up
- [[AWS]]

**Amazon Monitron** — An end-to-end system (sensors, gateway and app) that uses ML to detect abnormal machinery behavior for predictive maintenance.

**Category:** Industry

## Key concepts
- Wireless vibration/temperature sensors
- Gateways
- ML anomaly detection
- Mobile/web app for technicians
- Assets and sites

## Common CLI
| Command | Description |
|---|---|
| `Monitron app: commission sensors` | Set up assets and sensors |
| `Monitron app: review alerts` | Act on anomaly alerts |

## Pricing model
Per sensor plus a per-sensor annual service fee.

## Works well with
- IoT (backend)
- Mobile app
- Reporting/exports

## Use cases
- Predictive maintenance
- Equipment condition monitoring
- Reducing unplanned downtime
