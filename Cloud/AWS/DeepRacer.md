# DeepRacer

## Up
- [[AWS]]

**AWS DeepRacer** — A 1/18th-scale autonomous race car and service for learning reinforcement learning in a fun, hands-on way.

**Category:** Machine Learning

## Key concepts
- Reinforcement-learning models
- Reward functions
- Training in a simulator
- Virtual and physical racing leagues
- Model evaluation

## Common CLI
| Command | Description |
|---|---|
| `Console: DeepRacer -> Create model` | Train an RL model (console-driven) |
| `Console: Submit to a race` | Enter a racing league |

## Pricing model
Per training/evaluation hour in the simulator (plus optional hardware).

## Works well with
- SageMaker (RL)
- S3
- CloudWatch

## Use cases
- Learning reinforcement learning
- ML education and events
- Team-building challenges
