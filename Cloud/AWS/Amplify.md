# Amplify

## Up
- [[AWS]]

**AWS Amplify** — Full-stack platform to build, ship and host web and mobile apps, with hosting, backend and libraries.

**Category:** Front-End Web & Mobile

## Key concepts
- Amplify Hosting (Git-based CI/CD)
- Backend (data, auth, storage, functions)
- Amplify Libraries and UI components
- Preview environments
- Custom domains and SSR

## Common CLI
| Command | Description |
|---|---|
| `aws amplify create-app` | Create an Amplify app |
| `aws amplify create-branch` | Connect a branch |
| `aws amplify start-deployment` | Trigger a deployment |

## Pricing model
Per build minute and per GB hosted/served, plus backend resource usage.

## Works well with
- Cognito, AppSync
- DynamoDB, S3
- CloudFront

## Use cases
- Full-stack web/mobile apps
- Static and SSR hosting
- Rapid prototyping
