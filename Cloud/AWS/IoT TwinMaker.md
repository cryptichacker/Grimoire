# IoT TwinMaker

## Up
- [[AWS]]

**AWS IoT TwinMaker** — Builds digital twins of real-world systems by connecting existing data sources to 3D visualizations.

**Category:** IoT

## Key concepts
- Workspaces and entities/components
- Connectors to data sources
- 3D scenes
- Knowledge graph
- Grafana dashboard plugin

## Common CLI
| Command | Description |
|---|---|
| `aws iottwinmaker create-workspace` | Create a workspace |
| `aws iottwinmaker create-entity` | Create an entity |
| `aws iottwinmaker create-scene` | Create a 3D scene |

## Pricing model
Per query, entity and API usage.

## Works well with
- IoT SiteWise
- S3, Kinesis
- Managed Grafana

## Use cases
- Digital twins
- 3D operations dashboards
- Facility and factory modeling
