# Artifact

## Up
- [[AWS]]

**AWS Artifact** — Self-service portal to download AWS compliance reports (SOC, PCI, ISO) and review/accept agreements.

**Category:** Security

## Key concepts
- Compliance artifacts and reports
- Agreements (e.g., BAA)
- Account-level and organization agreements
- On-demand access

## Common CLI
| Command | Description |
|---|---|
| `aws artifact list-reports` | List available reports |
| `aws artifact get-report` | Download a report |

## Pricing model
Free.

## Works well with
- Organizations
- IAM

## Use cases
- Audit evidence
- Vendor due diligence
- Compliance documentation
