# Amazon Q Developer

## Up
- [[AWS]]

**Amazon Q Developer** — Generative-AI coding assistant that answers questions, writes and transforms code, and helps operate AWS.

**Category:** Developer Tools

## Key concepts
- Inline code suggestions in the IDE
- Chat in IDE, CLI and console
- Code transformation/upgrades
- Security scanning
- AWS resource Q&A

## Common CLI
| Command | Description |
|---|---|
| `q chat` | Chat with Q in the terminal |
| `q translate` | Turn natural language into a shell command |
| `(IDE plugin)` | Inline suggestions and chat |

## Pricing model
Free tier plus a per-user Pro subscription.

## Works well with
- IDEs (VS Code, JetBrains)
- CodeCatalyst
- AWS Console/CLI

## Use cases
- AI pair programming
- Code upgrades/migrations
- Operating AWS with natural language
