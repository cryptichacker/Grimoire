# CodeCatalyst

## Up
- [[AWS]]

**Amazon CodeCatalyst** — Unified DevOps service to plan, build and deliver software with integrated projects, repos, CI/CD and dev environments.

**Category:** Developer Tools

## Key concepts
- Spaces and projects
- Source repositories
- Workflows (CI/CD)
- Dev Environments (cloud IDEs)
- Blueprints
- Issues and dashboards

## Common CLI
| Command | Description |
|---|---|
| `aws codecatalyst list-spaces` | List spaces |
| `aws codecatalyst list-projects` | List projects |

## Pricing model
Free tier plus paid tiers by compute/storage usage.

## Works well with
- GitHub
- AWS accounts
- IAM Identity Center

## Use cases
- End-to-end DevOps
- Project scaffolding
- Cloud development environments
