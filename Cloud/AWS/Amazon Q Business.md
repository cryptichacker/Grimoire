# Amazon Q Business

## Up
- [[AWS]]

**Amazon Q Business** — A generative-AI assistant for the workplace that answers questions and takes actions over your enterprise data.

**Category:** Machine Learning

## Key concepts
- Applications and indexes
- Data source connectors
- Retrieval-augmented answers with citations
- Access control from source permissions
- Plugins/actions and admin controls

## Common CLI
| Command | Description |
|---|---|
| `aws qbusiness create-application` | Create an application |
| `aws qbusiness create-index` | Create an index |
| `aws qbusiness chat-sync` | Ask a question |

## Pricing model
Per user per month (subscription tiers).

## Works well with
- S3, SharePoint/Confluence connectors
- IAM Identity Center
- Kendra / Bedrock

## Use cases
- Enterprise knowledge assistant
- Document Q&A
- Workplace automation
