# Well-Architected Tool

## Up
- [[AWS]]

**AWS Well-Architected Tool** — Helps you review workloads against AWS best practices (the Well-Architected Framework) and track improvements.

**Category:** Management

## Key concepts
- Workloads and reviews
- Lenses (pillars + specialized)
- Questions and risk items
- Improvement plans
- Milestones over time

## Common CLI
| Command | Description |
|---|---|
| `aws wellarchitected create-workload` | Create a workload |
| `aws wellarchitected list-workloads` | List workloads |
| `aws wellarchitected get-lens-review` | Get a lens review |

## Pricing model
Free.

## Works well with
- Trusted Advisor
- Organizations
- Service Catalog

## Use cases
- Architecture reviews
- Risk identification
- Best-practice tracking
