# Supply Chain

## Up
- [[AWS]]

**AWS Supply Chain** — A cloud application that unifies supply-chain data and provides ML-powered insights to lower costs and mitigate risk.

**Category:** Business Applications

## Key concepts
- Data lake with supply-chain model
- Demand planning
- Inventory visibility and insights
- Risk alerts and recommendations
- Collaboration and work orders

## Common CLI
| Command | Description |
|---|---|
| `Console/App: connect data sources` | Ingest ERP/inventory data |
| `aws supplychain send-data-integration-event` | Send data via the API |

## Pricing model
By subscription tier plus usage.

## Works well with
- S3
- SageMaker
- QuickSight

## Use cases
- Supply-chain visibility
- Demand and inventory planning
- Risk mitigation
