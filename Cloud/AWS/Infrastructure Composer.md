# Infrastructure Composer

## Up
- [[AWS]]

**AWS Infrastructure Composer** — A visual designer to build serverless and infrastructure applications and generate CloudFormation/SAM templates.

**Category:** Developer Tools

## Key concepts
- Drag-and-drop canvas
- Cards for AWS resources
- Generates CloudFormation/SAM
- Local sync of the template
- Console and IDE (VS Code)

## Common CLI
| Command | Description |
|---|---|
| `Console: Infrastructure Composer` | Design visually and export a template |
| `VS Code: AWS Toolkit` | Edit the same template locally |

## Pricing model
Free (pay for the resources the generated templates create).

## Works well with
- CloudFormation / SAM
- Lambda, Step Functions
- VS Code Toolkit

## Use cases
- Visual IaC design
- Serverless app prototyping
- Learning CloudFormation
