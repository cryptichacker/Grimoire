# S3

## Up
- [[AWS]]

**Amazon Simple Storage Service** — Object storage that holds any amount of data as objects in buckets, with 11 nines of durability and multiple storage classes.

**Category:** Storage

## Key concepts
- Buckets and object keys
- Storage classes (Standard, IA, One Zone-IA, Glacier tiers, Intelligent-Tiering)
- Versioning and lifecycle rules
- Bucket policies, ACLs and Block Public Access
- Encryption (SSE-S3 / SSE-KMS)
- Presigned URLs, static website hosting, event notifications

## Common CLI
| Command | Description |
|---|---|
| `aws s3 mb s3://bucket` | Create a bucket |
| `aws s3 cp / sync` | Copy or sync files |
| `aws s3 ls` | List buckets/objects |
| `aws s3api put-bucket-policy` | Attach a bucket policy |

## Pricing model
Per GB-month by storage class plus request and data-transfer-out charges.

## Works well with
- CloudFront, Athena, Glue
- Lambda (event triggers)
- AWS Backup

## Use cases
- Backups and archives
- Data lakes
- Static website and media hosting
