# Wickr

## Up
- [[AWS]]

**AWS Wickr** — An end-to-end encrypted service for secure messaging, calling, file transfer and collaboration with strong controls.

**Category:** Business Applications

## Key concepts
- End-to-end encryption
- Rooms and direct messages
- Ephemeral/burn-on-read messages
- Data-retention and compliance controls
- Admin console/networks

## Common CLI
| Command | Description |
|---|---|
| `Admin console: create a network` | Provision a Wickr network |
| `Admin console: configure security groups` | Set retention/security policy |

## Pricing model
Per user per month by plan.

## Works well with
- IAM Identity Center
- S3 (compliance retention)
- CloudTrail

## Use cases
- Secure messaging
- Regulated/defense communications
- Confidential collaboration
