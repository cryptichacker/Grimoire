# Private 5G

## Up
- [[AWS]]

**AWS Private 5G** — Helps you set up and scale a private mobile network with the hardware, SIMs and software managed by AWS.

**Category:** Networking

## Key concepts
- Networks and network sites
- Managed radio units and SIMs
- Capacity and coverage planning
- Integration with AWS backends

## Common CLI
| Command | Description |
|---|---|
| `aws privatenetworks list-networks` | List private networks |
| `aws privatenetworks create-network` | Create a network |
| `aws privatenetworks list-network-sites` | List sites |

## Pricing model
Per network capacity/radio-unit subscription plus data.

## Works well with
- VPC
- IoT
- EC2 / Outposts

## Use cases
- Private mobile networks
- Industrial/campus connectivity
- Reliable device connectivity
