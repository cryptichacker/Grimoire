# Azure Health Bot

## Up
- [[Azure]]

**Azure Health Bot** — A managed platform to build compliant, AI-powered virtual health assistants with built-in medical intelligence.

**Category:** Industry

## Key concepts
- Healthcare-tuned NLP
- Built-in medical content/triage
- Scenario builder
- Compliance (HIPAA)
- Escalation to live agents

## Common CLI
| Command | Description |
|---|---|
| `Portal: Health Bot instance` | Create and configure a health bot |
| `Management API` | Automate scenarios/config |

## Pricing model
By tier plus message usage.

- Bot Service
- AI Language
- Communication Services

## Use cases
- Symptom checking/triage
- Patient self-service
- Healthcare virtual assistants
