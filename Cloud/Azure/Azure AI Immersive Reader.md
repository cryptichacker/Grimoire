# Azure AI Immersive Reader

## Up
- [[Azure]]

**Azure AI Immersive Reader** — An inclusively designed tool that embeds text-reading and comprehension features into applications.

**Category:** AI

## Key concepts
- Read-aloud (text-to-speech)
- Text spacing and syllable breaking
- Parts-of-speech highlighting
- Translation and picture dictionary
- Line focus

## Common CLI
| Command | Description |
|---|---|
| `az cognitiveservices account create --kind ImmersiveReader` | Create an Immersive Reader resource |
| `az cognitiveservices account keys list` | Get keys |

## Pricing model
Per page of content rendered (with a free tier).

## Works well with
- Web / mobile apps
- AI Translator
- AI Language

## Use cases
- Reading accessibility
- Language learning
- Inclusive UX
