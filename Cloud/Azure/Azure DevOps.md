# Azure DevOps

## Up
- [[Azure]]

**Azure DevOps** — A suite of developer services for planning, source control, CI/CD, testing and artifacts.

**Category:** Developer Tools

## Key concepts
- Azure Boards (work tracking)
- Azure Repos (Git)
- Azure Pipelines (CI/CD)
- Azure Test Plans
- Azure Artifacts (packages)
- Organizations and projects

## Common CLI
| Command | Description |
|---|---|
| `az devops project create` | Create a project |
| `az pipelines create` | Create a pipeline |
| `az repos create` | Create a Git repo |
| `az boards work-item create` | Create a work item |

## Pricing model
Free tier plus per-user and per-parallel-job charges.

## Works well with
- GitHub
- Azure Resource Manager
- Container Registry

## Use cases
- CI/CD pipelines
- Agile planning
- Source control and artifacts
