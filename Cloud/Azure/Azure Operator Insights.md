# Azure Operator Insights

## Up
- [[Azure]]

**Azure Operator Insights** — A managed service that ingests and analyzes massive volumes of telecom network data to deliver operational insights.

**Category:** Industry

## Key concepts
- Data products and ingestion agents
- Large-scale telemetry ingestion
- Prebuilt telecom analytics
- Data querying (ADX-based)
- Dashboards

## Common CLI
| Command | Description |
|---|---|
| `az network-analytics data-product create` | Create a data product |
| `az network-analytics data-product list` | List data products |

## Pricing model
By ingested/analyzed data volume.

## Works well with
- Data Explorer
- Operator Nexus
- Power BI / Grafana

## Use cases
- Telecom analytics
- Network performance insights
- Operator data at scale
