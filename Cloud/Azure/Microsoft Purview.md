# Microsoft Purview

## Up
- [[Azure]]

**Microsoft Purview** — A unified data governance, security and compliance platform to discover, classify, protect and manage data across the estate.

**Category:** Identity & Security

## Key concepts
- Data Map and Data Catalog
- Automated scanning and classification
- Sensitivity labels and DLP
- Data lineage
- Compliance and risk management
- Multicloud coverage

## Common CLI
| Command | Description |
|---|---|
| `az purview account create` | Create a Purview account |
| `az purview account list` | List accounts |
| `az purview account show` | Show account details |

## Pricing model
Per capacity/vCore for scanning plus governance/compliance features.

## Works well with
- Data Lake / SQL / Synapse
- Microsoft 365
- Fabric / Databricks

## Use cases
- Data governance
- Data classification/DLP
- Compliance management
