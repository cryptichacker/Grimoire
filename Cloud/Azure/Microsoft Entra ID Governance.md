# Microsoft Entra ID Governance

## Up
- [[Azure]]

**Microsoft Entra ID Governance** — Identity governance capabilities to ensure the right people have the right access to the right resources.

**Category:** Identity & Security

## Key concepts
- Entitlement management (access packages)
- Access reviews
- Privileged Identity Management (PIM)
- Lifecycle workflows
- Separation of duties

## Common CLI
| Command | Description |
|---|---|
| `Portal: Identity Governance` | Configure access packages/reviews/PIM |
| `Microsoft Graph API` | Automate governance tasks |

## Pricing model
Per governed user per month (Entra ID Governance license).

## Works well with
- Microsoft Entra ID
- Conditional Access
- Microsoft 365

## Use cases
- Access certification
- Just-in-time privileged access
- Joiner-mover-leaver automation
