# Microsoft Entra External ID

## Up
- [[Azure]]

**Microsoft Entra External ID** — Customer identity and access management (CIAM) for securing sign-in of external users, customers and partners.

**Category:** Identity & Security

## Key concepts
- External tenants
- Sign-up/sign-in user flows
- Social and enterprise federation
- Custom branding
- Conditional Access for external users
- Successor to Azure AD B2C

## Common CLI
| Command | Description |
|---|---|
| `az ad ... (Graph)` | Manage identities via Microsoft Graph |
| `Portal: External ID user flows` | Configure sign-up/sign-in flows |

## Pricing model
Per monthly active user (free tier included).

## Works well with
- App registrations
- API Management
- Conditional Access

## Use cases
- Customer sign-in (CIAM)
- Partner/B2B access
- Branded auth experiences
