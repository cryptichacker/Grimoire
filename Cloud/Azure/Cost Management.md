# Cost Management

## Up
- [[Azure]]

**Microsoft Cost Management** — Tools to monitor, allocate, forecast and optimize Azure (and AWS) spend with budgets and reports.

**Category:** Management

## Key concepts
- Cost analysis and views
- Budgets and alerts
- Cost allocation and tags
- Forecasting
- Exports to storage
- AWS connector

## Common CLI
| Command | Description |
|---|---|
| `az costmanagement query` | Query cost data |
| `az consumption usage list` | List usage details |
| `az costmanagement export create` | Schedule a cost export |

## Pricing model
Free for Azure cost management (small fee for AWS cost data).

## Works well with
- Azure Advisor
- Budgets/alerts (Monitor)
- Power BI

## Use cases
- Spend analysis
- Budgets and alerts
- Cost optimization
