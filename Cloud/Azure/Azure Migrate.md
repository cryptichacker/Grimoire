# Azure Migrate

## Up
- [[Azure]]

**Azure Migrate** — A central hub to discover, assess and migrate servers, databases, web apps and data to Azure.

**Category:** Migration

## Key concepts
- Discovery and assessment (appliance)
- Dependency mapping
- Server migration (agentless/agent)
- Database and web-app assessment
- Right-sizing and cost estimates

## Common CLI
| Command | Description |
|---|---|
| `Portal: Azure Migrate project` | Discover and assess workloads |
| `az migrate ...` | Limited CLI; mostly portal/appliance driven |

## Pricing model
Free assessment tools; pay for the migrated target resources.

## Works well with
- Site Recovery
- Database Migration Service
- Virtual Machines

## Use cases
- Migration planning
- Server/DB migration
- Cloud readiness assessment
