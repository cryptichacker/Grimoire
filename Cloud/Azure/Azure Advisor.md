# Azure Advisor

## Up
- [[Azure]]

**Azure Advisor** — A personalized recommendation engine that analyzes usage and suggests improvements across five categories.

**Category:** Management

## Key concepts
- Categories: cost, security, reliability, performance, operational excellence
- Recommendation digests
- Score
- Postpone/dismiss
- Integration with Well-Architected

## Common CLI
| Command | Description |
|---|---|
| `az advisor recommendation list` | List recommendations |
| `az advisor configuration list` | Show configuration |
| `az advisor recommendation disable` | Dismiss a recommendation |

## Pricing model
Free.
