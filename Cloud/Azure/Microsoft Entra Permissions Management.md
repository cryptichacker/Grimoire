# Microsoft Entra Permissions Management

## Up
- [[Azure]]

**Microsoft Entra Permissions Management** — A cloud infrastructure entitlement management (CIEM) product that discovers and right-sizes permissions across clouds.

**Category:** Identity & Security

## Key concepts
- Permissions Creep Index (PCI)
- Multicloud (Azure/AWS/GCP)
- Least-privilege recommendations
- Anomaly detection
- Automated remediation

## Common CLI
| Command | Description |
|---|---|
| `Portal: Permissions Management` | Onboard clouds and review permissions |
| `Microsoft Graph API` | Query permission insights |

## Pricing model
Per resource/identity billed monthly.

## Works well with
- Microsoft Entra ID
- Azure/AWS/GCP
- Microsoft Sentinel

## Use cases
- Least-privilege enforcement
- Multicloud permissions visibility
- CIEM
