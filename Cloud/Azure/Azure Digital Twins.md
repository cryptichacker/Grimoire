# Azure Digital Twins

## Up
- [[Azure]]

**Azure Digital Twins** — A platform to create digital models of real-world environments (buildings, factories, grids) and reason over live data.

**Category:** IoT

## Key concepts
- Digital Twins Definition Language (DTDL)
- Twin graph and relationships
- Live data ingestion
- Event routes
- Query API
- 3D Scenes Studio

## Common CLI
| Command | Description |
|---|---|
| `az dt create` | Create a Digital Twins instance |
| `az dt model create` | Upload a model |
| `az dt twin create` | Create a twin |

## Pricing model
Per message/operation and query units.

## Works well with
- IoT Hub
- Time Series / Data Explorer
- Functions, Event Grid

## Use cases
- Digital twins
- Smart buildings/factories
- IoT spatial intelligence
