# Microsoft Fabric

## Up
- [[Azure]]

**Microsoft Fabric** — An all-in-one SaaS analytics platform unifying data engineering, warehousing, science, real-time and BI on OneLake.

**Category:** Analytics

## Key concepts
- OneLake (unified data lake)
- Workloads: Data Factory, Warehouse, Lakehouse, Data Science, Real-Time, Power BI
- Capacities (F SKUs)
- Shortcuts and Direct Lake
- Copilot integration

## Common CLI
| Command | Description |
|---|---|
| `Portal: Fabric workspace` | Create workspaces and items (SaaS) |
| `az fabric capacity create` | Create a Fabric capacity |

## Pricing model
Per capacity (F SKU) per hour plus OneLake storage.

## Works well with
- OneLake / Data Lake Storage
- Power BI
- Synapse, Databricks

## Use cases
- Unified analytics (SaaS)
- Lakehouse + warehouse + BI
- Self-service data platform
