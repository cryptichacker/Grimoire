# Azure Bot Service

## Up
- [[Azure]]

**Azure Bot Service** — A managed environment to build, host and connect conversational bots to multiple channels.

**Category:** AI

## Key concepts
- Bot Framework SDK/Composer
- Channels (Teams, Web Chat, etc.)
- Direct Line
- Integration with language/AI services
- Bot registration and hosting

## Common CLI
| Command | Description |
|---|---|
| `az bot create` | Create a bot resource |
| `az bot show` | Show bot details |
| `az bot publish` | Publish bot code |

## Pricing model
Per message by channel (Standard channels free; Premium metered).

## Works well with
- Azure AI Language / Speech
- Azure OpenAI
- App Service / Functions

## Use cases
- Chatbots and virtual agents
- Multi-channel bots
- Conversational AI
