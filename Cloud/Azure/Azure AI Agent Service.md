# Azure AI Agent Service

## Up
- [[Azure]]

**Azure AI Agent Service** — A managed service (within AI Foundry) to build, deploy and scale enterprise AI agents that use tools and data.

**Category:** AI

## Key concepts
- Agents with instructions and tools
- Threads and runs
- Tool calling (functions, code interpreter, knowledge)
- Grounding with your data
- Tracing and evaluation

## Common CLI
| Command | Description |
|---|---|
| `Portal: AI Foundry -> Agents` | Create and configure agents |
| `SDK/REST` | Build agents programmatically |

## Pricing model
Per model/token usage plus tool/compute costs.

## Works well with
- Azure OpenAI / AI Foundry
- AI Search (grounding)
- Functions / Logic Apps

## Use cases
- Enterprise AI agents
- Tool-using assistants
- RAG-grounded automation
