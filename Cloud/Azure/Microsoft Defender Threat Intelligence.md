# Microsoft Defender Threat Intelligence

## Up
- [[Azure]]

**Microsoft Defender Threat Intelligence** — Delivers global threat intelligence — indicators, adversary profiles and infrastructure data — for hunting and investigation.

**Category:** Identity & Security

## Key concepts
- Threat-actor and tooling profiles
- IOC and infrastructure data
- Reputation and passive DNS
- Analyst insights and articles
- Integration with Sentinel/Defender

## Common CLI
| Command | Description |
|---|---|
| `Portal: Defender TI` | Investigate indicators and actors |
| `REST/Graph API` | Query threat intelligence data |

## Pricing model
Included/premium tiers; API usage may be billed.

## Works well with
- Microsoft Sentinel
- Defender XDR
- Defender EASM

## Use cases
- Threat hunting
- Investigation enrichment
- Adversary research
