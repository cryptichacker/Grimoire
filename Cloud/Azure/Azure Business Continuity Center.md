# Azure Business Continuity Center

## Up
- [[Azure]]

**Azure Business Continuity Center** — A unified management view to monitor and govern backup and disaster-recovery protection across the estate.

**Category:** Management

## Key concepts
- Unified protection dashboard
- Backup + Site Recovery visibility
- Protection gaps and compliance
- Security posture for BCDR
- At-scale governance

## Common CLI
| Command | Description |
|---|---|
| `Portal: Business Continuity Center` | Monitor BCDR protection |
| `az backup / az site-recovery` | Manage underlying protection |

## Pricing model
Free (pay for underlying Backup/ASR).

## Works well with
- Azure Backup
- Site Recovery
- Azure Policy

## Use cases
- BCDR governance
- Protection gap detection
- Compliance reporting
