# Azure API Center

## Up
- [[Azure]]

**Azure API Center** — A centralized inventory (catalog) of an organization's APIs to improve discovery, governance and consumption.

**Category:** Developer Tools

## Key concepts
- API inventory and versions
- Environments and deployments
- Metadata and governance
- API analysis (linting)
- VS Code integration

## Common CLI
| Command | Description |
|---|---|
| `az apic create` | Create an API Center |
| `az apic api create` | Register an API |
| `az apic api version create` | Add an API version |

## Pricing model
By tier plus API count.

## Works well with
- API Management
- Azure DevOps / GitHub
- VS Code

## Use cases
- API governance
- API discovery
- Enterprise API catalog
