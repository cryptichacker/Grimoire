# Azure Data Manager for Agriculture

## Up
- [[Azure]]

**Azure Data Manager for Agriculture** — A managed platform to ingest, unify and analyze agricultural data (satellite, sensor, farm operations) for agri solutions.

**Category:** Analytics

## Key concepts
- Farm hierarchy data model
- Connectors (satellite/weather/sensors)
- Solutions framework
- Model inference (crop/soil)
- APIs and SDK

## Common CLI
| Command | Description |
|---|---|
| `Portal/ARM: create the instance` | Provision Data Manager for Agriculture |
| `REST API` | Ingest and query ag data |

## Pricing model
By platform usage plus storage.

- Data Lake Storage
- Machine Learning
- Power BI

## Use cases
- Precision agriculture
- Farm data unification
- Crop/soil analytics
