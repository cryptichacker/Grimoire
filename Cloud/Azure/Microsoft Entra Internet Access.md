# Microsoft Entra Internet Access

## Up
- [[Azure]]

**Microsoft Entra Internet Access** — An identity-centric Secure Web Gateway (part of Global Secure Access) that protects access to internet and SaaS apps.

**Category:** Identity & Security

## Key concepts
- Secure Web Gateway (SWG)
- Web content and threat filtering
- Conditional Access integration
- Universal tenant restrictions
- Traffic forwarding profiles

## Common CLI
| Command | Description |
|---|---|
| `Portal: Global Secure Access` | Configure Internet Access policies |
| `Client: Global Secure Access agent` | Forward traffic from endpoints |

## Pricing model
Per user per month (Entra Suite / SSE licensing).

## Works well with
- Microsoft Entra ID
- Conditional Access
- Entra Private Access

## Use cases
- Secure internet access (SSE)
- SaaS/app protection
- Web filtering
