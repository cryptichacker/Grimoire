# Azure AI Content Understanding

## Up
- [[Azure]]

**Azure AI Content Understanding** — A generative-AI service that transforms unstructured multimodal content (documents, images, audio, video) into structured data.

**Category:** AI

## Key concepts
- Analyzers and schemas
- Field extraction across modalities
- Generative extraction
- Grounding and confidence
- Part of AI Foundry

## Common CLI
| Command | Description |
|---|---|
| `Portal: AI Foundry -> Content Understanding` | Build analyzers |
| `REST API` | Analyze content programmatically |

## Pricing model
Per content unit processed by modality.

## Works well with
- AI Foundry / Azure OpenAI
- Blob Storage
- AI Search

## Use cases
- Multimodal data extraction
- Document/media processing
- Content-to-data pipelines
