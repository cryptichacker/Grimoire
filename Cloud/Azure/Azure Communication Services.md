# Azure Communication Services

## Up
- [[Azure]]

**Azure Communication Services** — Developer APIs and SDKs to add voice, video, chat, SMS and email to applications, built on Teams infrastructure.

**Category:** Communication

## Key concepts
- Identities and access tokens
- Calling (voice/video) and chat
- SMS and email
- Phone number provisioning
- Teams interoperability
- Call automation

## Common CLI
| Command | Description |
|---|---|
| `az communication create` | Create a Communication Services resource |
| `az communication list` | List resources |
| `az communication phonenumber list` | List phone numbers |

## Pricing model
Per usage by channel (per minute, per message, per email).

## Works well with
- Azure AI Speech
- Event Grid
- Functions / App Service

## Use cases
- In-app calling/chat
- SMS and email notifications
- Telephony integration
