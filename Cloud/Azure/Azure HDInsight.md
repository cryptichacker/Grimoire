# Azure HDInsight

## Up
- [[Azure]]

**Azure HDInsight** — A managed, open-source analytics service running frameworks such as Apache Spark, Hadoop, Hive, Kafka and HBase.

**Category:** Analytics

## Key concepts
- Cluster types (Spark/Hadoop/Kafka/HBase)
- Managed open-source frameworks
- Autoscaling
- Enterprise Security Package
- Integration with Data Lake

## Common CLI
| Command | Description |
|---|---|
| `az hdinsight create` | Create a cluster |
| `az hdinsight list` | List clusters |
| `az hdinsight application create` | Add an application |

## Pricing model
Per cluster VM-hour by node type.

## Works well with
- Data Lake Storage
- Data Factory
- Power BI

## Use cases
- Big-data processing
- Open-source frameworks
- Streaming (Kafka)
