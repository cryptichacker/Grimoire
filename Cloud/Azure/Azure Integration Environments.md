# Azure Integration Environments

## Up
- [[Azure]]

**Azure Integration Environments** — Organizes and manages Azure Integration Services resources and models business processes for tracking.

**Category:** Integration

## Key concepts
- Integration environments (logical grouping)
- Business process modeling
- Transaction/step tracking
- Application-centric view
- Part of Azure Integration Services

## Common CLI
| Command | Description |
|---|---|
| `Portal: Integration Environments` | Group resources and model processes |
| `az resource ...` | Manage via ARM |

## Pricing model
By tracking/usage plus underlying services.

## Works well with
- Logic Apps
- Service Bus / Event Grid
- API Management

## Use cases
- Integration governance
- Business-process tracking
- Solution-centric management
