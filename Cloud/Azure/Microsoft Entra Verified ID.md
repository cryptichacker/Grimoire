# Microsoft Entra Verified ID

## Up
- [[Azure]]

**Microsoft Entra Verified ID** — A decentralized identity service for issuing and verifying digital, cryptographically secure verifiable credentials.

**Category:** Identity & Security

## Key concepts
- Verifiable credentials (W3C)
- Issuers and verifiers
- Decentralized identifiers (DIDs)
- Wallet-based presentation
- Trust system

## Common CLI
| Command | Description |
|---|---|
| `Portal: Verified ID setup` | Configure issuer/verifier |
| `Microsoft Graph API` | Issue/verify credentials programmatically |

## Pricing model
Per credential issued/verified transaction.

## Works well with
- Microsoft Entra ID
- Microsoft Authenticator
- Graph API

## Use cases
- Verifiable credentials
- Remote identity proofing
- Passwordless onboarding
