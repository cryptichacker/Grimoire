# Azure PlayFab

## Up
- [[Azure]]

**Azure PlayFab** — A complete backend platform for building, launching and operating live games (LiveOps).

**Category:** Gaming

## Key concepts
- Player identity and data
- Multiplayer servers and matchmaking
- Economy (catalogs/inventory)
- LiveOps (events, segments)
- Analytics and A/B testing
- CloudScript automation

## Common CLI
| Command | Description |
|---|---|
| `PlayFab CLI / Game Manager` | Manage titles and services |
| `PlayFab REST APIs` | Integrate game clients/servers |

## Pricing model
Free tier plus metered multiplayer/usage.

- Cosmos DB / Storage
- Communication Services

- Game backends
- Multiplayer and matchmaking
- LiveOps and player analytics
