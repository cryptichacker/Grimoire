# Microsoft Security Copilot

## Up
- [[Azure]]

**Microsoft Security Copilot** — A generative-AI security assistant that helps analysts investigate, respond to and report on security incidents.

**Category:** Identity & Security

## Key concepts
- Prompts and promptbooks
- Security Compute Units (SCU)
- Standalone and embedded experiences
- Plugins (Sentinel, Defender, Intune, third-party)
- Investigation and reporting assistance

## Common CLI
| Command | Description |
|---|---|
| `Portal: Security Copilot` | Provision capacity and run prompts |
| `API/plugins` | Extend with data sources |

## Pricing model
Per Security Compute Unit (SCU) per hour.

## Works well with
- Microsoft Sentinel
- Defender XDR
- Intune / Purview

## Use cases
- AI-assisted SOC
- Incident investigation
- Security reporting
