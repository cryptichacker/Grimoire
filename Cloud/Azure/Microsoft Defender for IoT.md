# Microsoft Defender for IoT

## Up
- [[Azure]]

**Microsoft Defender for IoT** — Provides asset discovery, vulnerability management and threat detection for IoT and operational-technology (OT) networks.

**Category:** Identity & Security

## Key concepts
- Network sensors (agentless OT monitoring)
- Device inventory and risk
- Behavioral anomaly detection
- OT/ICS threat intelligence
- Integration with Sentinel

## Common CLI
| Command | Description |
|---|---|
| `Portal: onboard sensors` | Deploy OT network sensors |
| `az iot ...` | Manage related IoT resources |

## Pricing model
Per monitored device per month.

## Works well with
- Microsoft Sentinel
- IoT Hub
- Defender for Cloud

## Use cases
- OT/ICS security
- IoT asset discovery
- Industrial threat detection
