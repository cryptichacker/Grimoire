# Azure AI Video Indexer

## Up
- [[Azure]]

**Azure AI Video Indexer** — Extracts deep insights from video and audio — transcripts, faces, objects, topics, sentiment and more.

**Category:** AI

## Key concepts
- Video/audio insights
- Transcription and translation
- Face and object detection
- Topic and keyword extraction
- Custom models (brands/people)
- Widgets and API

## Common CLI
| Command | Description |
|---|---|
| `Portal: Video Indexer account` | Create an account and upload media |
| `REST API / ARM` | Index and query videos programmatically |
