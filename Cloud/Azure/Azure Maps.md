# Azure Maps

## Up
- [[Azure]]

**Azure Maps** — Geospatial APIs and SDKs to add maps, search, routing, traffic and geofencing to web and mobile apps.

**Category:** Web

## Key concepts
- Render (maps/tiles)
- Search and geocoding
- Routing and traffic
- Geofencing and spatial operations
- Weather and time zones
- Creator (indoor maps)

## Common CLI
| Command | Description |
|---|---|
| `az maps account create` | Create a Maps account |
| `az maps account list` | List accounts |
| `az maps account keys list` | Get subscription keys |

## Pricing model
Per transaction/API call by category.

## Works well with
- App Service / Static Web Apps
- IoT / Digital Twins
- Functions

## Use cases
- Maps in applications
- Routing and logistics
- Geofencing and location intelligence
