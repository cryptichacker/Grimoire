# Azure Data Manager for Energy

## Up
- [[Azure]]

**Azure Data Manager for Energy** — A fully managed, OSDU-compliant data platform for the energy industry to unify and analyze subsurface and other data.

**Category:** Analytics

## Key concepts
- OSDU data platform (managed)
- Domain data services (well/seismic)
- Ingestion and search
- Entitlements
- Partition management

## Common CLI
| Command | Description |
|---|---|
| `Portal/ARM: create the instance` | Provision Data Manager for Energy |
| `OSDU APIs` | Ingest and query data |

## Pricing model
By platform capacity plus storage/usage.

## Works well with
- Data Lake Storage
- Databricks / Synapse
- Purview

## Use cases
- Energy/subsurface data
- OSDU workloads
- Exploration analytics
