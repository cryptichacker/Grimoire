# Copilot in Azure

## Up
- [[Azure]]

**Microsoft Copilot in Azure** — An AI companion embedded in the Azure portal and CLI that helps design, operate, troubleshoot and optimize Azure.

**Category:** Management

## Key concepts
- Natural-language assistance
- Generates CLI/PowerShell/Bicep
- Resource insights and troubleshooting
- Cost and optimization guidance
- Grounded in your environment

## Common CLI
| Command | Description |
|---|---|
| `Portal: Copilot in Azure` | Chat within the Azure portal |
| `az ... (generated)` | Run suggested commands |
