# Azure AI Health Insights

## Up
- [[Azure]]

**Azure AI Health Insights** — A service providing prebuilt AI models that surface relevant insights from unstructured healthcare data.

**Category:** AI

## Key concepts
- Health Insights models (trial matching, oncology, radiology insights)
- Structured output from clinical text
- Evidence and inferences
- REST API
- Responsible AI for health

## Common CLI
| Command | Description |
|---|---|
| `Portal/ARM: create Health Insights` | Provision the service |
| `REST API` | Submit clinical data for inference |
