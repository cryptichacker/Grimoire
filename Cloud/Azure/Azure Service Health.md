# Azure Service Health

## Up
- [[Azure]]

**Azure Service Health** — Provides personalized alerts and guidance about Azure service issues, planned maintenance and health advisories.

**Category:** Management

## Key concepts
- Service issues, planned maintenance and health advisories
- Resource Health
- Personalized dashboard
- Health alerts (action groups)
- Historical events

## Common CLI
| Command | Description |
|---|---|
| `Portal: Service Health` | View issues and configure alerts |
| `az monitor activity-log alert create` | Create a health alert |

## Pricing model
Free.

## Works well with
- Azure Monitor / action groups
- Azure Advisor
- Resource Graph

## Use cases
- Incident awareness
- Maintenance tracking
- Automated health notifications
